# BioRoute - Prototipo Java

Sistema de gestión logística y trazabilidad de alimentos orgánicos desarrollado como prototipo para la materia Seminario de Práctica de Informática.

## Ejecución

```bash
javac -d out src/modelo/*.java src/conexion/*.java src/dao/*.java src/util/*.java src/main/Main.java
java -cp out main.Main
```
